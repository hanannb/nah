# nah.hannan

Personal website — [nah-hannan.com](https://nah-hannan.com)

Bayesian methods, quant research, generative systems. Built to understand things.

## what's here

```
index.html          — single page, Mac OS classic shell
css/style.css       — CRT aesthetic, IBM Plex Mono + VT323
js/
  data.js           — all content: research, essays, library, tinkering
  essays.js         — full essay bodies (6 pieces)
  app.js            — rendering, navigation, puzzle, sign wall
  p5.min.js         — p5.js for generative sketches
  sketches/         — canvas 2D and p5 generative art
```

## sections

- **research** — active projects: thesis (Bayesian hierarchical asset pricing), DeepRGARCH, autodiff engine
- **essays** — longer pieces on tail risk, hyperbolic geometry in ML, generative art and probability, latent variables, overfitting, macro forecasting
- **library** — annotated reading list
- **tinkering** — math art (flow field, truchet, epicycles, phyllotaxis, Poincaré disk, vortex dipole) and builds
- **sign** — leave an equation
- **▒** — SVD puzzle (drag σ₂ to zero)

## stack

Static HTML/CSS/JS. No framework, no build step. Hosted on GitHub Pages with a custom domain.
