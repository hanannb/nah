# nah.hannan

A personal research archive, in prototype form, presented in a retro Macintosh-style interface.

**Live:** [hanannb.github.io/nah](https://hanannb.github.io/nah/)

The site collects research notes, essays, an annotated reading list and small mathematical builds. Its main subjects are Bayesian methods, quantitative finance and risk, and statistical computing.

## Sections

- **Research:** a project log, including a hybrid EGARCH–LSTM volatility model and a higher-order autodiff engine
- **Essays:** short pieces on risk, probability and machine learning
- **Library:** annotated books on statistics, maths, ML, finance and philosophy
- **Tinkering:** generative sketches (Canvas 2D and p5.js), each with notes on the maths behind it, plus a hidden SVD explorer

## Stack

Plain HTML, CSS and JavaScript, with no framework and no build step. Content lives in `js/data.js`. The site uses a strict Content Security Policy and has no tracking. It is hosted on GitHub Pages.
